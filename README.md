# Marija — portfolio

Statičan portfolio bez frameworka: HTML, CSS i mali vanilla JavaScript sloj.

## Pokretanje

```bash
pnpm dev
```

Otvori [http://localhost:3000](http://localhost:3000).

## Struktura

- `index.html` — početna, sav portfolio sadržaj u jednom hero ekranu
- `kontakt.html` — jedina posebna stranica
- `styles.css` — kompletan vizuelni sistem i responsive stilovi
- `script.js` — hero tabovi i HR/EN prevod

Izbor jezika se čuva u browseru, pa ostaje isti i nakon prelaska na kontakt.
